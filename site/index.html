Web security school project

Practice web security in a fake school portal.

SecureEd is an intentionally vulnerable PHP app. I added Docker support, cleaner pages, and three labs about password resets and sessions.

Run with Docker Read the beginner guide

What I added

The extension work

  • Nginx and PHP-FPM containers that start with one command
  • Cleaner forms, navigation, tables, and dashboards
  • Three new CWE labs
  • A separate static website with a beginner guide

What it teaches

Main learning goals

  • Why Docker makes a project easier to run on different computers
  • Why password reset links need a secret token
  • Why old sessions should expire
  • Why a session ID should change after login

Three new labs

Try each weakness one at a time.

CWE-640

Weak password recovery

See how a predictable reset flow can let an attacker choose a new password without a secret token.

CWE-613

Insufficient session expiration

Simulate an old session and observe what happens when protected pages only check that it exists.

CWE-384

Session fixation

Choose a known session ID and watch it remain attached after login when regeneration is omitted.
